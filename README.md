# Traffic speed forecasting on METR-LA with graph neural networks

Team T005. Can 207 Los Angeles freeway sensors forecast their own speed better by listening to
their upstream and downstream neighbours? This branch (`phase2-deep-learning`) holds the
deep-learning phase and only what it needs to train, predict and be compared fairly.
The full Phase 1 work (EDA, random forest, tuning, ablation, LaTeX report) stays on `main`.

**Result:** ST-GAT forecasts 60 minutes ahead with 3.46 mph test MAE, against 3.65 for
XGBoost with neighbour features (5.3% lower, 95% CI 4.3–6.2). Removing the road edges from
the same network removes the gain. Details: [`deep_learning/README.md`](deep_learning/README.md)
and [`reports/dl_results_summary.md`](reports/dl_results_summary.md).

## Layout

```
deep_learning/   models, training, Kaggle launcher, notebooks 10-15, dashboard, presentation (start here)
src/             shared data pipeline: loading, split, scaler, graph, metrics, evaluation
notebooks/       04, 05, 05b: the comparison baselines (persistence, seasonal average, XGBoost, XGBoost + neighbours)
data/            raw-data sources and checksums; committed split, scaler and sensor order in data/processed
artifacts/       training histories, summaries, attention and per-sensor gain (models and predictions are rebuilt)
reports/         dl_results_summary.md, generated by notebook 14
tests/           data alignment, splits, graph, metrics, notebook structure
```

## Quick start

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r deep_learning/requirements-dl.txt
python -m deep_learning.prepare_data --download    # raw data + data/processed
python -m pytest tests deep_learning/tests -q
```

Then run the baseline notebooks 04, 05, 05b (they write the comparison predictions), train the
deep-learning models (see [`deep_learning/README.md`](deep_learning/README.md#reproduce)), and run
notebooks 10–15.

```bash
streamlit run deep_learning/dashboard/app.py       # interactive dashboard
python -m deep_learning.presentation.build         # writes deep_learning/presentation/index.html
```

## Ground rules used throughout

* Chronological, day-aligned split: 83 / 12 / 24 days (train / validation / test); never random.
* A speed of 0 is a sensor outage: masked in inputs, never scored as a target.
* Scaling fitted on training data only; cyclic time-of-day and day-of-week features.
* Every model scored on the same test points (common mask); predictions clipped to 0–70 mph.
* Nothing here controls real traffic.
